# Next Steps

The active roadmap is [docs/roadmap/ROADMAP.md](docs/roadmap/ROADMAP.md).

Before taking a roadmap item:

1. Check [current product status](docs/specs/00-global/PRODUCT_SCOPE_AND_STATUS.md).
2. Update or add the canonical spec.
3. Define acceptance criteria.
4. Create a scoped implementation plan.
5. Preserve protected production behavior.
6. Verify and update status after completion.

Current high-level product gaps include full scheduling, reviews and ratings,
automated payments/refunds, stronger centralized RBAC, complete module
enforcement and production observability. The roadmap does not mean these
features are already available.
