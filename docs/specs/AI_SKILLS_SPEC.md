# AI SKILLS SPEC

Страница `/admin/ai` содержит:
- пост для Telegram;
- акция;
- описание товара/услуги;
- ответ на отзыв;
- идеи контента на 7 дней;
- текст рассылки;
- модерация текста;
- улучшить текст продавца;
- описание бизнеса.

AI учитывает `Business.type`. Лимиты считаются через `AIUsageLog`, дневная проверка - `checkBusinessAiLimit`.

Планы:
- FREE: mock/дешёвая модель, 5 запросов в день, черновики;
- START: 20 запросов, посты и акции;
- PRO: 100 запросов, модерация и расписание;
- BUSINESS: 300 запросов, брендовый стиль и контент-план.
