# SELLER ADMIN SPEC

Seller Admin - светлый кабинет продавца. Продавец работает только со своим `businessId`.

Для cart-бизнесов:
- Панель;
- Заказы;
- Товары;
- Клиенты;
- ИИ-маркетинг;
- Настройки.

Для booking-бизнесов:
- Панель;
- Записи;
- Услуги;
- Мастера;
- Расписание;
- Клиенты;
- ИИ-маркетинг;
- Настройки.

Продавцу нельзя показывать Super Admin, все бизнесы, создание SaaS-клиентов, чужие заказы, глобальные тарифы и чужие AI-логи.
