# Delivery Flow Specification

## 1. Область

Доставка является способом получения заказа конкретного бизнеса. Она включает
зону, стоимость, адрес, назначение курьера и отдельный delivery status.

## 2. Настройки бизнеса

Владелец задаёт:

- включена ли доставка;
- включён ли самовывоз;
- базовую стоимость/время, если используются;
- зоны;
- минимальную сумму;
- срок принятия курьером;
- активных курьеров.

Manager не управляет этими настройками по умолчанию.

## 3. Зона

Зона содержит:

- название;
- район/область;
- стоимость;
- минимальную сумму;
- ориентировочное время;
- активность;
- порядок;
- архив.

Checkout использует только активную неархивную зону текущего бизнеса.

## 4. Snapshot

Заказ сохраняет:

- zone id, если доступен;
- название зоны;
- район;
- delivery fee;
- адрес клиента.

Будущее изменение зоны не меняет заказ.

## 5. Подготовка продавцом

После принятия продавец готовит заказ и переводит его в готовность к доставке.
До этого курьер не должен считать заказ готовым к получению.

## 6. Назначение

Варианты:

- владелец назначает активного курьера;
- доступная доставка публикуется подходящим курьерам;
- первый допустимый курьер атомарно забирает её.

Курьер и заказ должны принадлежать одному бизнесу.

## 7. Courier workflow

`WAITING_COURIER/ASSIGNED -> ACCEPTED_BY_COURIER -> PICKED_UP -> DELIVERING -> DELIVERED`.

- Конкурентное принятие защищено.
- Курьер не доставляет до получения.
- Клиент и продавец получают ключевые изменения.
- Завершённое назначение не переиспользуется.

## 8. Просрочка

Если срок получения истёк:

- assignment освобождается;
- история не удаляется;
- заказ возвращается в ожидающее состояние;
- курьер получает уведомление;
- stock и payment не меняются.

## 9. Отмена

- Продавец закрывает активное assignment.
- Курьер получает уведомление.
- Клиент получает бизнес-статус заказа.
- Отмена не удаляет delivery snapshot.

## 10. Контакты и карты

- Телефоны и адрес показываются только для выполнения доставки.
- Внешняя карта открывается по существующему адресу.
- Система не выдумывает координаты.
- Отсутствие карты не блокирует основной ручной delivery flow.

## 11. Ошибки

- Доставка вне зоны отклоняется.
- Уже занятый заказ возвращает conflict.
- Неверная последовательность возвращает понятную причину.
- Повторный клик не создаёт второй assignment.
