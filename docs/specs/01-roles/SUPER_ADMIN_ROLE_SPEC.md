# Super Admin Role Specification

## 1. Назначение роли

`SUPER_ADMIN` управляет SaaS-платформой Vitrina AI. Это единственная роль,
которая может работать со списком всех бизнесов и коммерческим доступом.

## 2. Основные задачи

- видеть глобальную сводку;
- создавать и подключать бизнес;
- выбирать тип и шаблон;
- назначать владельца;
- формировать seller invite/linking flow;
- видеть список бизнесов и их состояние;
- отмечать оплату коммерческого тарифа;
- активировать, блокировать, архивировать и восстанавливать бизнес;
- просматривать глобальные заказы и записи для поддержки;
- контролировать AI usage и request logs;
- скрывать и повторно публиковать отзывы с сохранением истории;
- входить в контекст выбранного бизнеса как продавец;
- запускать разрешённые demo/seed операции.

## 3. Права

Super Admin может выполнять seller-операции только после явного выбора бизнеса.
Глобальный доступ не отменяет tenant context: действие должно иметь понятную
цель и не смешивать данные разных бизнесов.

## 4. Коммерческий контроль

Super Admin:

- фиксирует сумму и дату оплаты;
- задаёт access status;
- указывает причину блокировки;
- сохраняет данные при архивировании;
- отвечает за восстановление.

Операции должны быть идемпотентными и совместимыми с legacy-полями доступа.

## 5. Запреты и предосторожности

Даже Super Admin не должен:

- физически удалять production-историю обычным UI;
- выполнять database reset;
- раскрывать секреты и bot tokens;
- подтверждать клиентский перевод без оснований;
- использовать demo seed как production reset;
- менять production URL на localhost, ngrok или preview origin;
- смешивать бизнесы в одном seller-контексте.

## 6. Поддержка продавца

При входе в выбранный бизнес интерфейс должен явно показывать, что управление
выполняется от имени Super Admin. Выход или смена бизнеса должны быть понятными,
чтобы действие не применилось к неверному tenant.

## 7. Статус реализации

`IMPLEMENTED`: создание бизнеса, глобальные списки, доступ, основные метрики и
AI logs.

`PARTIAL`: настройки платформы и тарифная система не являются полноценным
централизованным control plane.

## 8. Критерий успешной роли

Super Admin может подключить и поддержать бизнес, не вмешиваясь в данные другого
бизнеса случайно и не используя прямое редактирование production БД.
