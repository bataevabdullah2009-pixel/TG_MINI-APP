# Courier Role Specification

## 1. Назначение роли

`COURIER` выполняет доставку заказов одного бизнеса. Это отдельная роль с
минимально необходимым доступом к данным заказа.

## 2. Рабочие списки

Курьер видит:

- доступные доставки своего бизнеса и подходящей зоны;
- доставки, назначенные ему;
- ограниченный список завершённых доставок.

## 3. Данные заказа

Для выполнения доставки курьер может видеть:

- название и адрес продавца;
- имя и телефон клиента;
- адрес и район доставки;
- комментарий, относящийся к доставке;
- состав и сумму заказа;
- стоимость доставки;
- способ и состояние оплаты;
- текущий delivery status.

Данные используются только для выполнения конкретной доставки.

## 4. Разрешённые действия

- взять доступную доставку;
- принять прямое назначение;
- связаться с продавцом или клиентом;
- открыть адрес во внешней карте, если ссылка доступна;
- отметить получение заказа у продавца;
- после получения отметить движение к клиенту;
- после движения отметить доставку завершённой.

## 5. Последовательность

Базовая последовательность:

`AVAILABLE -> ACCEPTED_BY_COURIER -> PICKED_UP -> DELIVERING -> DELIVERED`.

- Одну доступную доставку может забрать только один курьер.
- `PICKED_UP` невозможен до принятия.
- `DELIVERING` невозможен до получения.
- `DELIVERED` невозможен до состояния в пути.
- Повторное действие не создаёт второй assignment или уведомление.

## 6. Ограничения

Курьер не может:

- видеть заказы другого бизнеса;
- брать заказ вне своей рабочей зоны, если зона задана;
- менять состав, цену, скидку и адрес заказа;
- менять seller order status произвольно;
- подтверждать перевод владельца;
- управлять каталогом, клиентами и настройками;
- назначать других курьеров;
- читать не относящиеся к доставке операции.

## 7. Просроченное назначение

Если курьер не выполнил требуемое принятие в установленный срок, назначение
может быть освобождено. Заказ возвращается в доступную очередь без удаления
истории. Клиенты и продавец получают уведомления только там, где это полезно.

## 8. Критерий успешной роли

Курьер видит достаточно данных для доставки, не видит лишнюю информацию и не
может нарушить последовательность выполнения.
