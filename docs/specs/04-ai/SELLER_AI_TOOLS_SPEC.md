# Seller AI Tools Specification

## 1. Назначение

AI продавца ускоряет создание черновиков. Результат не публикуется и не меняет
операционные данные без явного действия пользователя.

## 2. Поддерживаемые задачи

- описание товара или услуги;
- Telegram-пост;
- акция;
- ответ на отзыв, когда отзывы будут реализованы;
- идеи контента;
- текст рассылки;
- улучшение текста;
- описание бизнеса;
- image prompt и генерация изображения, если provider доступен;
- moderation suggestion.

## 3. Контекст

- AI получает только выбранный business scope.
- Учитывает тип бизнеса, товар и входные данные продавца.
- Не читает чужие клиенты, заказы и AI logs.
- Super Admin использует инструмент только в явном контексте бизнеса.

## 4. Черновик

- Результат помечается как черновик.
- Продавец может отредактировать, сохранить или отказаться.
- Сохранённый MarketingPost не равен опубликованному посту.
- Автопубликация имеет статус `PLANNED`, если не реализован отдельный канал.

## 5. Ограничения

AI не меняет:

- цену;
- stock;
- availability;
- order/payment/booking status;
- коммерческий доступ;
- Telegram routing.

AI не выдумывает скидку или гарантию, если продавец их не указал.

## 6. Cost control

- Учитываются дневной и месячный лимиты бизнеса.
- Логируются provider, model, feature, объём и status.
- Cache допустим для безопасных повторяемых задач.
- Ошибка provider возвращает понятный fallback.
- Mock provider используется только там, где это явно допустимо.

## 7. Модели и providers

Поддержка provider abstraction не означает, что каждый provider production-ready.
Фактический provider определяется окружением и настройкой бизнеса. Секреты не
передаются клиенту.

## 8. Качество

- Текст соответствует задаче и языку.
- Фактические поля сверяются с данными.
- Рискованные обещания отмечаются.
- Результат не содержит prompt leakage или секреты.
- При недостатке данных AI задаёт вопрос или создаёт нейтральный черновик.
