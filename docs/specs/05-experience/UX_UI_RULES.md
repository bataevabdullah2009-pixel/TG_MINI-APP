# UX and UI Rules

## 1. Общие правила

- Основной язык пользовательских текстов - русский.
- Интерфейс mobile-first и пригоден для Telegram viewport.
- Основное действие заметно, но destructive действие не маскируется.
- Loading, empty, success и error states обязательны.
- Технические коды не заменяют понятное сообщение.
- Длинный контент не ломает карточки и кнопки.
- Safe area учитывается для нижней навигации и checkout.

## 2. Marketplace

- Чёткий заголовок Vitrina AI.
- Поиск и фильтры доступны без длинной прокрутки.
- Карточка показывает бизнес, а не отдельный товар.
- Статус `Открыто/Закрыто` не перепутан с коммерческой блокировкой.
- Избранное имеет мгновенную обратную связь.
- Пустой результат отличается от ошибки.

## 3. Storefront

- Название бизнеса постоянно понятно.
- Категории, поиск и карточки не смешивают tenant context.
- Цена и наличие читаемы.
- Кнопка disabled объясняет отсутствие товара.
- Cart bar показывает количество и сумму.
- Checkout открывается как единый законченный процесс.
- Booking использует подходящие date/time pickers.

## 4. Checkout

- До отправки видны состав и итог.
- Скидка и доставка показаны отдельными строками.
- Перевод объясняет ручную проверку.
- Submit блокируется во время запроса.
- При конфликте stock корзина не очищается без объяснения.
- Успех показывает номер и путь к истории.

## 5. Рабочие кабинеты

- Роль и выбранный бизнес видны.
- Основная очередь доступна быстро.
- Фильтры не скрывают данные без понятного состояния.
- Опасные действия требуют ясной формулировки.
- Super Admin mode визуально отличается от обычного seller context.
- Manager не видит недоступные коммерческие действия.

## 6. Визуальная система

Текущий визуальный дизайн сохраняется, пока отдельная задача не требует
редизайна:

- marketplace - тёмный premium header;
- seller - светлый операционный кабинет;
- Super Admin - SaaS-панель;
- шаблоны используют согласованные акцентные темы.

Спек не разрешает менять дизайн как побочный эффект backend/docs/hotfix задачи.

## 7. Accessibility

- Интерактивные элементы имеют достаточную область нажатия.
- Цвет не является единственным индикатором статуса.
- Иконки с неочевидным смыслом имеют label.
- Focus и keyboard interaction сохраняются в браузерном режиме.
- Изображения имеют безопасный alt или декоративный empty alt.
