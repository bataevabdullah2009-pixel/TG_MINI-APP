# Reviews and Ratings Specification

## 1. Статус

`IMPLEMENTED` после применения manual SQL patch и успешной проверки Prisma.
Рейтинг на карточке бизнеса рассчитывается только по опубликованным отзывам.

## 2. Право на отзыв

- Отзыв оставляет Telegram-авторизованный клиент.
- Основанием является `COMPLETED` заказ, успешно доставленный `DELIVERED` заказ
  или `COMPLETED` запись.
- Одна операция даёт не более одного отзыва.
- Отзыв связан с business и исходной операцией.
- Чужая операция не даёт права на отзыв.
- Нельзя передать Telegram user id или author id через request body.

## 3. Содержимое

- рейтинг: целое число 1-5;
- комментарий: необязателен;
- дата;
- безопасное snapshot-имя клиента;
- статус модерации.

## 4. Модерация

Статусы MVP:

- `PUBLISHED`;
- `HIDDEN`.

Super Admin может скрыть мошеннический, незаконный или оскорбительный контент.
Автор модерации и время скрытия сохраняются. Продавец не удаляет и не скрывает
отзывы.

## 5. Расчёт рейтинга

- Участвуют только `PUBLISHED` отзывы.
- Показываются среднее и количество.
- Скрытый отзыв исключается.
- Расчёт нельзя заменять константой.
- Небольшое количество отзывов должно быть понятно пользователю.

## 6. Anti-fraud

- Ownership проверяется сервером.
- Нельзя доверять order id, business id или Telegram id из body.
- Уникальные ограничения не допускают два отзыва на один order или booking.
- Применяется ограничение частоты создания отзывов.
- Продавец не может создавать отзывы от имени клиента.

## 7. Acceptance gate

Функция не переводится в `IMPLEMENTED`, пока нет:

- моделей данных и safe SQL patch;
- customer UI;
- seller read-only UI;
- moderation flow;
- расчётного рейтинга marketplace;
- проверок ownership и дублей.
