# Seller Product Management Specification

## 1. Список товаров

Seller panel должен поддерживать:

- поиск по названию и описанию;
- фильтр по категории;
- фильтр по типу: товар/услуга;
- фильтр `В наличии`, `Нет в наличии`, `Скрытые`, `Архив`;
- отображение цены, stock, доступности, категории и archive state.

## 2. Быстрые действия

На карточке без открытия полного редактора:

- `-1` и `+1` для позиций со `stock != null`;
- изменение количества на точное значение;
- быстрое изменение цены;
- тумблер `В наличии / Нет в наличии`, изменяющий `isAvailable`;
- архивирование;
- восстановление из архива.

Операции должны проверять целые неотрицательные значения и быть идемпотентными там, где это возможно.

## 3. Полное редактирование

Карточка редактирования содержит:

- тип, название, описание;
- цену;
- категорию;
- изображение;
- режим stock;
- количество;
- `isAvailable`;
- popular flag;
- длительность услуги.

## 4. Архивирование

- Кнопка `Удалить` в product UI означает архивирование.
- API `DELETE` не выполняет physical delete, а устанавливает `archivedAt` и `isAvailable = false`.
- Архивная позиция не отображается клиенту.
- Старые `OrderItem` продолжают отображаться по snapshot.
- Восстановление снимает `archivedAt`; доступность продавец включает отдельно или явно при восстановлении.

## 5. Цена

- Изменение цены не обновляет существующие `OrderItem`.
- Checkout всегда берёт актуальную цену из БД, а не из payload клиента.
- Если продавец меняет уже созданный заказ, клиент должен увидеть изменение; для MVP предпочтительно отменить заказ и создать новый, если перерасчёт не реализован полностью.
