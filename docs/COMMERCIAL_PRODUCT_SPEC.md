# Vitrina AI: Commercial Product Specification

## 1. Назначение MVP 1.0

Vitrina AI - Telegram Mini App SaaS для локального бизнеса. Один бизнес получает публичную витрину, seller panel, заказы/записи, оплату наличными или переводом, доставку и AI-помощников.

Документ является источником правды для коммерческого доступа. Детальные процессы описаны в связанных `*_SPEC.md`.

## 2. Коммерческая модель

- Единственный тариф MVP: `LIFETIME`.
- Цена: `50 000 RUB`.
- Ежемесячные подписки в MVP не используются.
- Super Admin вручную фиксирует оплату.
- Поля бизнеса: `planType`, `paidAmount`, `paidAt`, `accessStatus`, `blockedReason`.
- До подтверждения оплаты допускается демо/онбординг по решению Super Admin, но production-доступ должен быть явно активирован.

## 3. Статусы доступа

`ACTIVE`
- Клиент видит бизнес в marketplace и может открыть `/app/[businessSlug]`.
- Продавец может управлять бизнесом.
- Заказы и записи разрешены при соблюдении остальных правил.

`BLOCKED`
- Бизнес скрыт от клиентов и не принимает новые заказы/записи.
- Продавец видит экран: `Доступ заблокирован, свяжитесь с администратором`.
- История, товары, клиенты, заказы и файлы не удаляются.
- `blockedReason` доступен Super Admin и продавцу.

`ARCHIVED`
- Бизнес закрыт и скрыт от клиентов.
- Новые операции запрещены.
- История сохраняется, восстановление разрешено.

## 4. Управление доступом

- Только Super Admin может активировать, блокировать, архивировать и восстанавливать бизнес.
- Продавец может отправить запрос на закрытие, но не должен физически удалять бизнес.
- Блокировка и архивирование должны быть идемпотентными.
- При восстановлении Super Admin явно выбирает `ACTIVE`.
- Совместимые legacy-поля (`isActive`, `subscriptionStatus`) синхронизируются с `accessStatus`, пока они используются production-кодом.

## 5. Инварианты данных

- Нельзя каскадно удалять историю заказов при закрытии бизнеса.
- Активные заказы перед архивированием должны быть завершены или отменены.
- Архивирование не меняет snapshot цен, доставки и состава старых заказов.
- Production URL, Telegram webhook URL и bot routing не зависят от тарифа и не хардкодятся.
