# User Stories

Канонический список:
[specs/05-experience/USER_STORIES.md](specs/05-experience/USER_STORIES.md).

Критические истории первого продавца:

- клиент находит бизнес, оформляет заказ и видит статус;
- продавец видит заказ и вручную проверяет перевод;
- курьер последовательно завершает доставку;
- клиент оставляет отзыв только после завершённой операции;
- Super Admin управляет доступом бизнеса и модерацией отзывов;
- Telegram AI отвечает только по данным БД.
