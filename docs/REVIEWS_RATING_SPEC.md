# Reviews and Rating Specification

## 1. Кто может оставить отзыв

- Только авторизованный клиент после `COMPLETED` заказа или записи.
- Один подтверждённый заказ/booking даёт не более одного отзыва.
- Произвольный пользователь без связанной операции не может создать отзыв.

## 2. Содержимое

- рейтинг: целое число 1-5;
- комментарий необязателен;
- связь с business и order/booking обязательна;
- продавец может оставить один публичный ответ.

## 3. Модерация

- Статусы: `PENDING`, `APPROVED`, `REJECTED`.
- Super Admin может скрывать мошеннический, незаконный или оскорбительный контент.
- Модерация не должна тихо изменять оценку клиента.
- Причина модерации сохраняется.

## 4. Средний рейтинг

- Считаются только `APPROVED` отзывы.
- Среднее и количество отзывов пересчитываются из подтверждённых данных.
- Удалённый/отклонённый отзыв не участвует в рейтинге.

## 5. Anti-fraud

- Сервер проверяет ownership заказа/записи.
- Нельзя доверять `telegramUserId`, order id или business id только из body.
- Rate limit и audit log рекомендуются для production.
