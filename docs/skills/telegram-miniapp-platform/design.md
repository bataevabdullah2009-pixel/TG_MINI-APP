# Design Guidelines (дизайн)

This document defines the premium UI/UX guidelines and rules for the Telegram Mini App Platform.

## 1. Marketplace Design
- **Header**: Dark premium header with search and status info.
- **Search**: Large prominent search input.
- **Categories**: Icon-based horizontal categories.
- **Business Cards**: Neat grid of businesses showing their status and categories.
- **Navigation**: Bottom persistent navigation bar.

## 2. Business Mini App Themes
Businesses are styled dynamically based on `Business.templateKey` and their target industry:
- **Cafe**: Orange / warm palette.
- **Barbershop**: Black / gold palette.
- **Shop**: Blue / purple palette.
- **Grocery**: Green palette.
- **Hardware**: Dark / orange palette.
- **Carwash**: Cyan / blue palette.

## 3. Seller Admin Panel
- **Layout**: Clean light dashboard.
- **Sidebar**: Easy-to-understand sidebar navigation.
- **Actions**: Large, accessible buttons for order processing.

## 4. Super Admin Panel
- **Layout**: Dark SaaS-panel.
- **Components**: Glassmorphism cards ("glass cards").
- **Content**: Summary stats and quick action triggers.
