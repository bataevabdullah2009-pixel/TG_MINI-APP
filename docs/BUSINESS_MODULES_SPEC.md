# BUSINESS MODULES SPEC

`Business.modulesEnabled` хранит список возможностей через запятую.

Основные модули:
- `catalog`;
- `cart`;
- `delivery`;
- `pickup`;
- `booking`;
- `staff`;
- `calendar`;
- `profile`;
- `ai`.

Mini App и seller sidebar должны показывать только функции, которые соответствуют шаблону и modules.
