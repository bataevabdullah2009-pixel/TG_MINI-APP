# TEMPLATE SYSTEM SPEC

Renderer выбирается по `business.templateKey`:
- `cafe` -> меню, корзина, заказ;
- `barbershop` -> услуги, мастера, дата, время, запись;
- `shop` -> каталог, поиск, корзина, заказ;
- `grocery` -> продукты, количество, доставка, акции, заказ;
- `hardware_store` -> каталог, поиск, заявка/заказ, консультация;
- `carwash` -> услуги, тип сервиса, дата, время, запись.

Нельзя показывать booking-функции в cart-бизнесах и наоборот. Capabilities берутся из шаблона и `modulesEnabled`.
