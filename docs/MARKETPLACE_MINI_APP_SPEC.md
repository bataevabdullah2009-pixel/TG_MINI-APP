# MARKETPLACE MINI APP SPEC

`/app` открывает каталог Vitrina AI.

Функции:
- загрузка активных бизнесов из `/api/marketplace/businesses`;
- поиск по названию, описанию и типу;
- фильтры: Все, Еда, Барбершопы, Магазины, Продукты, Хозмаг, Автомойки;
- карточка: логотип/буква, название, тип, адрес, рейтинг, открыт/закрыт, кнопки `Открыть` и `Избранное`;
- избранное хранится в `localStorage`, а при наличии Telegram user id дополнительно сохраняется через API;
- Super Admin видит кнопку `Админ-панель`, если Telegram id входит в `TELEGRAM_SUPER_ADMIN_IDS`.

Если бизнесов нет, показывается пустое состояние: `Пока нет подключённых бизнесов.`
