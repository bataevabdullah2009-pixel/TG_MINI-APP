# Roadmap

## MVP до сдачи

- Стабилизировать production Mini App entry `/app`.
- Проверить каталог бизнесов, карточку бизнеса, корзину и checkout.
- Проверить подтверждение телефона через Telegram contact.
- Проверить, что заказ создается и виден продавцу.
- Проверить seller panel: заказы, записи, товары, медиа, настройки.
- Проверить Super Admin: список бизнесов, создание/подключение продавца.
- Проверить Telegram bot: BotFather button, webhook, Vercel URL.
- Проверить Supabase schema patches.
- Убедиться, что Prisma errors не показываются пользователю сырым текстом.
- Обновить документацию и QA checklist.

## После сдачи

- Добавить smoke tests для ключевых routes.
- Добавить health dashboard для Vercel/Supabase/Telegram.
- Улучшить onboarding продавца.
- Сделать мастер настройки бизнеса.
- Расширить аналитику заказов и клиентов.
- Улучшить обработку edge cases в checkout и booking.
- Добавить audit log для действий продавца и Super Admin.

## Коммерческая версия

- Тарифные ограничения по количеству товаров, заказов, AI-запросов и медиа.
- Billing и subscription lifecycle.
- Self-service подключение бизнеса.
- Белая маркировка для продавцов.
- Несколько филиалов одного бизнеса.
- SLA monitoring, error reporting, backup policy.
- Автоматизированное подключение Telegram bot для каждого продавца.

## Подключение реальных продавцов

- Сценарий Super Admin onboarding.
- Проверка Telegram ID owner.
- Шаблоны бизнеса по типам: кафе, магазин, барбершоп, автомойка, продукты, хозмаг.
- Импорт товаров из CSV/таблицы.
- Настройка логотипа, обложки, адреса и контактов.
- Пробный заказ после подключения.

## Платежи

- Поддержать ручную оплату/наличные как базовый режим.
- Добавить YooKassa или другой provider.
- Добавить Telegram Stars, если продуктовая модель подходит.
- Хранить payment status в `Payment`.
- Добавить чек/receipt и retry сценарии.
- Разделить order status и payment status.

## Уведомления

- Seller notification: новый заказ, новая запись, отмена, изменение статуса.
- Client notification: статус заказа, подтверждение записи, напоминание.
- Fallback, если у бизнеса нет `telegramAdminChatId`.
- Настройки уведомлений на уровне бизнеса.
- Логи доставки уведомлений.

## AI генератор товаров и постов

- Генерация описания товара/услуги.
- Генерация Telegram-поста.
- Генерация промо-акций.
- Модерация текста.
- Лимиты по тарифам.
- История AI-запросов и cost tracking.
- Шаблоны prompts под тип бизнеса.
